## 4. 投放建议（通用）

1. **节奏**：v1.0 发布前 3 天起铺内容（预告 1 条 → 发布当天 3 条 → 一周内 2 条/平台），
   保持 30 天内容日历，每周至少 2 条原创 + 1 条用户 UGC 转播。
2. **素材复用**：对话卡片（1080×1350）可裁切为小红书 3:4 首图；竖屏录屏裁切后
   直接用于抖音 9:16；B 站用 16:9 演示长视频 + 竖屏短视频互相引流。
3. **数据回收（T-42 联动）**：落地链接统一走 GitHub Release 短链或官网下载页，
   按平台/文案打标（utm_source=xhs/zhihu/bili/douyin）；转化漏斗看下载→激活→
   留存，KOL 按 CPM 与转化率复盘，不只看播放量。
4. **KOL 分层**：头部（>50 万粉）1-2 个做品牌声量；腰部（5-50 万）3-5 个做
   深度演示；尾部/素人（<5 万）10 个以上铺 UGC，优先“桌宠/效率/AI”垂类。
5. **社区承接**：GitHub Discussions + QQ/Discord 放评论区，皮肤创作者激励
   （分成 70%）从 UGC 中招募首批 10 名创作者。
6. **合规底线**：所有内容标注“AI 生成/演示”；不承诺疗效或绝对隐私；不引导
   未成年人付费；不使用夸大“治愈/上瘾”类违禁词。
