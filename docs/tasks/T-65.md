### 批判性自检（ADR-050）

1. 信号真实性：状态来自 Codex rollout JSONL 元数据（task_started/function_call/custom_tool_call/token_count/写入时间），实现前对本机真实会话事件结构做了实测；非模拟、非装饰。
2. 不造假：无假百分比；waiting 仅“回合未结束+静默 ≤5 分钟”显示并超时回落；review 仅在 approval/review/permission 关键词命中时显示；未实现 failed（当前 rollout 无显式失败事件）记录为残余风险，不假装支持。
3. 用户体验场景：Codex 长任务→working+工具标签（用户知道在跑什么）；用户离开→waiting；需要批准→attention；聊天/朗读/提醒/任务气泡优先，探针不抢占；浮窗隐藏/开关关闭不轮询；多会话取最新 rollout。
4. 隐私：只解析 type/name/status/timestamp，尾部 ≤64KB，不读取/展示会话正文；模块纯 Node 无 electron 依赖，check 断言保证。
5. 性能：5s 轮询 + 尾读 64KB + 可见性/开关早退。

### 残余风险

- 旧会话静默 ≤5 分钟仍显示“等待输入”（超时后回落 idle）；回合结束无显式事件时与“等待”不可区分，属信号边界。
- review 检测为 best-effort 关键词（当前版本 rollout 未观测到显式审阅事件）。
- 多会话并发时以最新写入的 rollout 为准。
- 实时性受 5s 轮询粒度限制；浮窗动画行复用 working/attention（waiting 已有行6），无独立 Codex 审阅行。
