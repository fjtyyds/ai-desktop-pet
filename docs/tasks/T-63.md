# T-63：任务级进度气泡（契约已冻结）

- 状态：已完成（已验收合并，2026-08-13，a7b31d8）
- 分支：codex/m5x-taskbubble
- worktree：E:\codex\AI桌宠-m5x-settings
- 目标：宠物浮窗显示结构化任务进度（标题/阶段/百分比/结果），运行中任务气泡优先、提醒排队补放；接入皮肤批量导入与自动更新下载。

## 契约（总工已冻结，worker 只读）

- `petAPI.petOverlay.startTask({ id, title, message?, percent?, stage?, totalStages? })` → `{ ok, task }`
- `petAPI.petOverlay.updateTask({ id, percent?, message?, stage? })` → `{ ok, task }`
- `petAPI.petOverlay.finishTask({ id, ok, message? })` → `{ ok, task: null }`
- `petAPI.petOverlay.getConfig()` → `{ bubbleEnabled, bubbleSeconds, reminders }`（T-57/T-61 契约补实现）
- IPC：`pet:task-start` / `pet:task-update` / `pet:task-finish`
- 状态事件 `pet:status-updated` payload 增加 `task` 字段（无任务为 null）
- 字段约束：id ≤64、title/message ≤80、percent 0~100（null=不确定）、stage/totalStages 可选整数

## 范围

1. `src/main/pet-overlay.js`：任务注册表（Map）；startTask/updateTask/finishTask IPC 处理器；currentStatus/notifyStatus 携带 task；运行中任务气泡优先（pushBubble 入 pending 队列，任务结束后补放，队列上限沿用 3）；finishTask 后按气泡时长显示 done/failed 结果再回落 idle；getConfig 补实现。
2. `src/main/preload.js`：暴露 startTask/updateTask/finishTask/getConfig 与通道常量。
3. `src/main/skin-store.js`：`scanCodexPetsDir(sourceDir, onProgress?)` 增加可选进度回调（每处理一个包回调 `{ index, total, name, error? }`；缺省不回调，现有调用不变）。
4. `src/main/ipc.js`：支持 `getPetOverlay` 注入（main.js 传入）；`handleSkinImportCodexPets` 用任务 API 包裹批量导入（开始/按包更新/结束）。
5. `src/main/updater.js` + `src/main/main.js`：updater 增加可选 `onDownloadProgress`（percent）回调；main.js 将其转发为浮窗任务（id=`app-update`，仅打包版真实触发，开发模式可单元验证回调链路）。
6. `src/renderer/overlay.html/css/js`：气泡内增加进度条元素（overlay-bubble-progress/bar/label）；status.task 非空时渲染标题/消息/百分比/阶段；任务结束隐藏进度条；尊重 bubbleEnabled 与 reduceMotion；`window.__overlayTest` 增加 getTask 钩子。
7. `src/shared/locales/zh-CN.json`、`en.json`：任务气泡相关文案。
8. `scripts/check.js`：T-63 静态断言（通道/API/渲染元素/队列优先逻辑 token）+ 运行时断言（start→update→finish、进度清洗、提醒补放）。
9. `scripts/smoke.js`：T-63 端到端（startTask 后气泡显示标题与进度条、updateTask 更新百分比、任务期间 pushBubble 不打断、finishTask 显示结果并回落 idle、getConfig 可用）。
