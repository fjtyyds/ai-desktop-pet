## 实现记录（2026-08-09）

- 已实现：
  - `src/llm/provider.js`：`chatStream({ messages }, { onDelta, signal })`，`stream:true`
    SSE 解析（含跨 TCP 块半截 JSON 缓冲），首字节 30 秒/整体 60 秒超时，AbortSignal 取消；
  - `src/llm/mock.js`：`chatStream` 把整段回复拆成 2 字符小段、每段 30~60ms 延迟，支持取消；
  - `src/llm/chat.js`：`sendStream(input, clientHistory, { onDelta, signal })`，上下文组装、
    成功持久化与记忆抽取与 `send()` 完全一致；取消返回 `{ ok:false, reply: 已收到部分, error:'已取消' }`
    且不持久化（与 send 错误路径一致）；旧 Provider 无 chatStream 时降级整段返回；
  - `src/main/ipc.js`：新增 `chat:send-stream` / `chat:delta` / `chat:stream-cancel`，
    同一时刻仅一个活动流，新流先取消旧流；
  - `src/main/preload.js`：暴露 `chat.sendStream` / `chat.onDelta`（返回退订函数）/ `chat.cancelStream`；
  - `src/renderer/chat.js`：流式优先发送，“正在思考…”占位、打字机增量更新，
    流式中发送按钮变为“停止”（点击取消）；无流式通道时兼容旧 `chat.send`；
  - `src/shared/locales/zh-CN.json`、`en.json`：新增 thinking/stop/cancelled 文案。
- 校验结果：
