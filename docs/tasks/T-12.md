## 完成记录（2026-08-09）

### 实施内容

- 新增 `src/shared/locales/zh-CN.json`、`en.json` 与双端复用翻译模块 `src/shared/locales/index.js`：
  - 主进程（Node）：同步 fs 读取 JSON，导出 `resolveLocale/getMessages/createTranslator/translate`；
  - 渲染进程（浏览器）：`<script>` 直接加载同一模块，fetch 读取同一份 JSON，暴露 `window.PetLocales`（无需新增 IPC/改 preload，契约不变）；
  - `resolveLocale`：`zh*` → zh-CN，其他（含 en*）→ en，空值回退 zh-CN；`settings.language='system'` 由调用方用系统语言解析。
- `src/storage/store.js`：`DEFAULT_SETTINGS.language='system'`；`writeSettings` 允许列表登记 `language` 并清洗（非法值保留当前值）；`readSettings` 归一化。
- `src/main/tray.js`：托盘 tooltip/菜单文案走 locale；语言取自设置（`system` 时用 `app.getLocale()`）；监听 `settings.json` 变化自动刷新菜单，右键打开前也刷新。
- `src/renderer/index.html`：静态文案加 `data-i18n`/`data-i18n-placeholder`/`data-i18n-title`/`data-i18n-aria-label`（中文保留为加载前回退文本）；新增界面语言下拉（跟随系统/简体中文/English）；聊天与设置区加 `role="region"` + 本地化 aria-label；引入 `../shared/locales/index.js`。
- `src/renderer/chat.js`：启动先 `await PetLocales.ready`；`applyStaticText` 统一应用语言包（含 `document.documentElement.lang`、`document.title`、meta、服务状态、宠物名标题）；设置页语言保存经 `petAPI.settings.set` 持久化并在保存后即时切换；设置/聊天视图切换时管理焦点。
- `src/renderer/chat.css`、`styles.css`：`:focus-visible` 全局高亮 + 各控件聚焦样式；语言下拉样式；弱化文字（hint/note/meta/占位符）与主按钮对比度修正（`#4f6ef7` → `#4160de`，悬停 `#4a66ea`）；字体栈加 Segoe UI。

### 验收结果

- `npm run check`：通过（全部 OK）。
- `npm run smoke`：通过（渲染页加载、历史恢复、表单端到端气泡 4）。
- 脚本化端到端（临时 Electron 进程，已验证后清理）：
  - 默认 en 设置加载：`document.lang=en`、标题 AI Pet、发送 Send、设置 Settings、meta/aria/占位符全部英文；
  - 设置页切 zh-CN 并保存：界面即时切换中文，`settings.json` 持久化；
  - 重载页面后仍为 zh-CN（持久化生效）；
  - 托盘（Node 假 Electron 模块验证）：en/zh-CN/跟随系统（en-US 与 zh-CN 系统）菜单与 tooltip 均正确；settings.json 变化后 watcher 自动刷新菜单。
- 无障碍走查（脚本计算 + 样式扫描）：
  - ARIA：主要按钮均有本地化 aria-label/title；聊天/设置区为 `role="region"`；消息列表 `aria-live="polite"`、状态区 `role="status"` 保持；
  - 焦点：`:focus-visible` 规则 5 处（全局、icon-btn、chat-input、send/primary-btn、field-input/select）；编程 focus 时浏览器默认 focus ring 仍可见，键盘 Tab 走自定义高亮；
  - 对比度（WCAG AA ≥ 4.5，脚本实测）：发送/保存按钮 5.31（修复前 4.28，已修）、fieldLabel 7.64、fieldHint 6.24、settingsNote 6.24、meta 5.61、输入框 9.14、占位符 10.99、serviceStatus 5.90 —— 无阻断项。
