## 协议规格（协调者已验证，参考实现：E:\codex\AI桌宠\test-edge-tts.js 未入库临时文件）

- 连接：`wss://speech.platform.bing.com/consumer/speech/synthesize/readaloud/edge/v1?TrustedClientToken=6A5AA1D4EAFF4E9FB37E23D68491D6F4&ConnectionId=<uuidhex>&Sec-MS-GEC=<token>&Sec-MS-GEC-Version=1-143.0.3650.75`
- Sec-MS-GEC：`winTicks = (floor(unixSeconds) + 11644473600)`，向下取整到 300 秒，乘 10000000；`sha256(winTicks + 固定token)` 大写 hex
- WebSocket 头（用 `ws` 包）：User-Agent 为 Chrome/143 + Edg/143；Origin=`chrome-extension://jdiccldimpdaibmpdkjnbmckianbfold`；Cookie=`muid=<32位大写hex>;`；Pragma/Cache-Control/Accept-Language
- 发送顺序（text 帧）：① speech.config（X-Timestamp 用 JS 风格日期 `Fri Aug 10 2026 ... GMT+0000 (Coordinated Universal Time)`，Path:speech.config，body 为 `{"context":{"synthesis":{"audio":{"metadataoptions":{"sentenceBoundaryEnabled":"true","wordBoundaryEnabled":"false"},"outputFormat":"audio-24khz-48kbitrate-mono-mp3"}}}}`）；② SSML（Path:ssml，X-Timestamp 末尾额外补 `Z`——微软 Edge bug，必须保留）
- SSML 模板：`<speak version='1.0' xmlns='http://www.w3.org/2001/10/synthesis' xml:lang='zh-CN'><voice name='<voice>'><prosody pitch='<pitch>' rate='<rate>' volume='+0%'><escaped text></prosody></voice></speak>`；文本必须 XML 转义（& < > " '），并把控制字符（0-8、11-12、14-31）替换为空格
- 长文本：按 ≤4096 字节 UTF-8 切分（优先换行/空格，避免截断多字节字符与 XML 实体），逐段合成后拼接 MP3
- 二进制帧：前 2 字节大端头长度 N；`buf[0:N]` 为头（含 `Path:audio`、`Content-Type:audio/mpeg`）；音频载荷从 `buf[N+2:]` 开始；收到 text 帧含 `Path:turn.end` 时关闭连接并返回全部音频
- 超时：连接 10s、整体 20s；失败返回 `{ ok:false, error }`，渲染层回退 speechSynthesis

## 验收标准

1. 开启专属语音包后朗读使用在线神经语音；6 套人格音色明显不同（不同说话人 + rate/pitch）
2. 断网/合成失败时自动回退系统 TTS，朗读按钮不失效、不卡死
3. 停止朗读、切换语言/人格、关闭开关等旧行为正常
4. `npm run check` 通过；`npm run smoke` 通过或说明原因
5. 主进程 LRU 缓存（建议 ≤10 条）避免重复请求；无密钥、无第三方 TTS 依赖（仅 ws）
