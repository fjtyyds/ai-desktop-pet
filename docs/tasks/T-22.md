## 技术验证结论（2026-08-10，ADR-023 门禁）

Open-Meteo 免费无密钥接口验证通过，无需用户配置 API Key：

- `geocoding-api.open-meteo.com/v1/search`：城市 → 经纬度（中英文均可，实测 HTTP 200）
- `api.open-meteo.com/v1/forecast`：`current` 参数返回温度/湿度/体感/风速/weather_code（实测 HTTP 200）
- 实测：上海 26°C（Light rain showers，湿度 93%）；北京 24°C（多云）
- 失败降级验证：模拟网络失败时返回最近一次成功数据 + `cached` 标记（渲染层提示“显示上次成功数据”）
- 结论：采用 Open-Meteo；全部网络请求在主进程发起（渲染层 CSP `connect-src 'self'` 不放开外部地址）
