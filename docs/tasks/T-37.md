## 验收标准

1. `app.isPackaged === false` 时绝不检查更新
2. 打包后检查 GitHub Releases（feed 来自 electron-builder 生成的 app-update.yml）；当前无更新/失败均静默或仅日志，不崩溃、不阻塞启动
3. 发现更新：弹原生 dialog 确认 → 下载（显示进度或等待）→ 下载完成提示重启安装（quitAndInstall）
4. 托盘菜单“检查更新”可用，双语文案正确
5. `npm run check` 通过；`npm run smoke` 通过或说明原因
6. 无法在本机实测真实更新（无已发布版本）时，写明验证策略（如 mock/代码走查），不得伪造通过
