1. 拖动窗口到屏幕边缘（≤24px）松手后立即吸附对齐，不缩成细条、不自动隐藏

3. 缩放时保持贴齐；重启后恢复吸附位置
4. `npm run check` 通过；`npm run smoke` 通过或说明原因
