- 目标：修复 T-65 自动化目检实测的两个真实缺陷，并补回归断言（ADR-053）。

## 缺陷（自动化目检证据）

1. 工具标签翻译 key 大小写错误：浮窗显示“Codex 正在工作：overlay.codexToolshell”（未翻译原始 key）。
   根因：main.js formatText 用 `t('overlay.codexTool' + toolKey)`，toolKey 为小写（shell/edit/search/other），
   而 locale key 为大写首字母（codexToolShell/codexToolEdit/codexToolSearch/codexToolOther）。
2. 探针状态卡死：working 由探针推入后（replaceStatus 持久化），Codex 静默转 waiting/attention 时
   shouldTakeOver 排除 working，探针无法再接管，浮窗永久显示“正在工作”。
   根因：探针未跟踪自己推过的状态，无法区分“聊天 working”与“探针 working”。

## 修复

1. `src/main/main.js`：工具标签 key 首字母大写（`codexTool${toolKey.charAt(0).toUpperCase()}${toolKey.slice(1)}`）。
2. `src/main/codex-status.js`：
   - 新增 `lastPushed`：仅在 setStatus 成功时记录探针自推状态；
   - `shouldTakeOver`：当前状态等于 lastPushed 时允许接管（working→waiting/attention），
     聊天/TTS 推的 working（文案不同）仍不覆盖；任务气泡仍最高优先；
   - `createCodexStatusProbe` 增加可选 `detect` 注入（默认 detectCodexStatus），便于确定性测试状态接管。
3. `scripts/check.js`：T-66 静态断言（main.js 大写 key、codex-status.js lastPushed/detect）+ 运行时断言
   （注入 detect：idle→working→waiting→attention 全链路；聊天 working 不被覆盖）。
