## 完成记录（2026-08-09）

### 已实现

- `src/llm/chat.js`：统一上下文组装（ADR-012）
  - system = persona + mood：T-06 `persona.js` 合入后调用 `buildSystemPrompt({ settings, mood })`；缺失时使用内置默认人格；mood 缺失时降级为不注入。
  - 短期窗口：最近 `DEFAULT_SHORT_TERM_WINDOW`（20）条，来自本地历史；`history` 缺省时主进程从 storage 读取。
  - 长期记忆：最多 `MAX_MEMORIES_IN_CONTEXT`（3）条，按“短消息关键词 + 最近使用时间”简单相关度选取，以【长期记忆】标注注入 system；命中后更新 `lastUsedAt`。
  - 每轮成功后异步触发记忆抽取（真实 API Key 且 memory-store 可用时）；抽取/保存失败只记录日志，不阻塞 UI 回复。
  - `send` 兼容 `{ text, history? }` 与旧内部调用 `(text, clientHistory)`；渲染层传入的 history 仅用于上下文窗口，不重复持久化。
- `src/renderer/chat.js`：`init` 时调用 `petAPI.history.get` 恢复历史气泡；接口缺失或失败时降级为默认问候；发送只传 `{ text }`，不再传全量历史。
- `scripts/check.js`：新增 M2 契约常量、renderer 历史恢复集成、chat 服务降级收发/短期窗口/长期记忆注入与异步抽取断言。
- `scripts/smoke.js`：改为临时 userData 隔离测试数据；注册 IPC；预置历史消息验证启动历史恢复（T-05 未合入时跳过）；表单发送端到端气泡断言。
