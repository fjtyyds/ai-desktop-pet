## 实现记录（2026-08-10，第 1 次尝试）

- 系统状态小部件（CPU/内存/电池）：
  - `src/main/main.js` 用 `os.cpus()` 差值计算 CPU 使用率、`os.totalmem()/freemem()`
    计算内存占用，电池百分比在 Windows 上经 `powershell Get-CimInstance Win32_Battery`
    查询（15s 缓存一次，避免频繁拉起子进程），插拔电经 `powerMonitor` 事件即时刷新；
  - 状态推送复用既有 `idle:event` 主进程→渲染层通道，以 `payload.type='system-status'`
    与 T-15 空闲互动区分（preload/ipc 不在任务边界内，这是唯一不越界的通道）；
  - 渲染层小部件面板显示 CPU/内存/电池数字并随推送刷新，内存附带已用/总 GB
    tooltip，电池状态（充电中/使用电池/电源）有独立文案与无障碍标签。
- 本地番茄钟：
  - 渲染层本地计时（开始/暂停/继续/重置/停止），显示 mm:ss，设置页可配时长
    （`pomodoroMinutes`，1~120 分钟）与提醒开关（`pomodoroEnabled`）；
  - 计时结束写入 settings 通知信号（`pomodoroNotifyAt`/`pomodoroNotifyMinutes`，
    store.js 白名单登记），主进程随状态轮询消费信号并弹系统 Notification
    （按设置语言本地化），弹后清零避免重复；关闭提醒开关时仅界面计时不弹通知；
  - 小部件面板右上角 ✕ 可收起并持久化（`widgetsEnabled`），设置页可重新开启。
- 边界说明：`activity:poke` 的 preload 包装为零参数（payload 无法传递），
  故番茄钟完成信号改用 settings 通道（store.js 在任务边界内）；以上通道复用与
  信号方案已在 main.js/chat.js 注释中说明。
- 校验：`npm run check` 通过；`npm run smoke` 通过（真实用户权限）；
  纯 Node 验证通过（store 默认值/清洗/钳制、CPU/内存/电池状态读取、通知本地化）；
  临时 Electron 端到端验证通过（状态数字 23%/57%/67% 刷新、电池状态文案、
  番茄钟 1.2s 短计时到 00:00、完成信号写入并消费清零、面板收起）。
