- 新增 `src/main/task-runner.js`：
  - `runWithTask(overlay, { id, title, totalStages? }, runner)` → Promise
  - 行为：`overlay?.startTask?.({ id, title, totalStages? })` → `await runner({ update })`（update 包装为 `overlay?.updateTask?.({ id, ...payload })`）→ 成功后 `overlay?.finishTask?.({ id, ok: true, message: result?.message })` 并返回 result；runner 抛错时 `overlay?.finishTask?.({ id, ok: false, message: error 截断 80 })` 后重新抛出。
