- 实现要求：
  1. 多显示器：petOverlayBounds 保存时带 displayId（screen.getDisplayMatching 或所在 display.id）；启动/恢复时校验该显示器仍存在且坐标在工作区内，否则回退主显示器右下角（避开任务栏，用 workArea）。
  2. 状态推送：pet:set-status/push-bubble 时主进程主动 webContents.send('pet:status-updated', status) 给浮窗；浮窗保留 5s 低频心跳轮询兜底（避免丢事件）。
  3. 浮窗隐藏/页面不可见（document.visibilitychange）时暂停 CSS 动画与轮询定时器；恢复可见时立即同步状态。
  4. 初始默认位置基于主显示器 workArea 右下角（现有逻辑确认），避免任务栏遮挡。
  5. 新增 IPC `pet:get-overlay-state`（返回 {enabled, visible, status}）供冒烟与心跳；preload 暴露。
