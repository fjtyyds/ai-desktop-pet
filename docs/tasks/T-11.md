## 完成记录（2026-08-09）

### 实现

- 新建 `src/main/crash.js`：
  - require 时即安装 `process.on('uncaughtException')` / `process.on('unhandledRejection')`，
    同步追加写入 `userData/logs/app.log`，留痕后保持进程存活（不静默退出）。
  - `initCrash({ dumpDir })` 调用 Electron `crashReporter.start`：
    `uploadToServer: false`（仅本地、不上传）、`rateLimit: false`、`compress: true`，
    并写入启动日志。
  - dump 目录默认 `userData/crashes`，可用环境变量 `AI_PET_CRASH_DUMP_DIR` 或
    `initCrash({ dumpDir })` 覆盖；通过 `app.setPath('crashDumps', dumpDir)` 生效。
- `src/main/main.js`：主实例分支内、app ready 前调用 `initCrash()`（渲染进程创建前完成初始化）。
- `.gitignore`：新增 `logs/`、`crashes/`、`*.dmp`。

### 验收结果

- `npm run check` 通过。
- `npm run smoke` 通过（渲染页加载、历史恢复、chat 端到端）。
- 隔离 Electron 进程模拟未捕获异常与未处理 Promise 拒绝：进程存活（`alive: true`），
  `logs/app.log` 两条记录齐全，dump 目录可配置且存在，`uploadToServer=false`。
- 隔离 Electron 进程执行 `process.crash()`：在自定义目录
  `<userData>/custom-crashes/reports/` 生成 `.dmp`（约 1.17 MB）。
- 真实应用（`electron . --userData=临时目录`）启动 6 秒存活，默认
  `userData/crashes` 与 `userData/logs/app.log` 正常创建，crashReporter 初始化无报错。
