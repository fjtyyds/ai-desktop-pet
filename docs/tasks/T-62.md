- 目标：提供开箱即用的动画宠物包（Codex 兼容 pet.json + spritesheet.webp 8×9 图集），并沉淀可复用生成脚本。

## 范围

1. `scripts/make-pet-pack.js`（新）：Electron 主进程脚本（`node_modules\.bin\electron` 运行），创建隐藏 BrowserWindow 用 canvas 2D 像素画风绘制 8 列×9 行动画图集（每格 128×128，整体 1024×1152），`toDataURL('image/webp', 0.9)` 导出 `spritesheet.webp`；同时生成 `preview.webp`；零新增 npm 依赖。
2. `src/main/default-skins/pixel-pet/`（新）：内置动画皮肤，`pet.json` 为 `{ id: 'pixel-pet', displayName: '像素小宠', description, spritesheetPath: 'spritesheet.webp', preview: 'preview.webp' }`。
3. 行语义与 `src/renderer/overlay.js` STATE_ROWS 一致：row0 idle（呼吸/眨眼）、row3 speaking/waving（挥手）、row4 excited/jumping（跳跃）、row5 sad/failed（垂头）、row6 attention/waiting（左右张望）、row7 working（打字起伏）、row8 ready（欢呼）；row1/row2 可自由设计（如行走/睡眠）。每行动画 8 帧。
4. `scripts/check.js` 新增 T-62 断言：生成脚本存在、pixel-pet 包文件存在、skin-store 运行时解析该内置图集通过（复用 WebP 尺寸校验）。
