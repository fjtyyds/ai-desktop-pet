# 皮肤包格式（T-43，MVP）

状态：已完成（待协调者验收）｜日期：2026-08-11｜对应任务卡：T-43

## 1. 包结构

皮肤包是“JSON 清单 + PNG 资源”的集合，支持两种载体：

- **目录**：选中一个文件夹，`manifest.json` 必须在文件夹根目录；
- **zip**：单个 `.zip` 文件，条目同样以根目录下的 `manifest.json` 为入口（导出即此格式）。

示例：

```text
manifest.json
preview.png            # 列表预览图（必填）
assets/
  idle.png             # 角色默认形象（roleAssets 引用）
```

## 2. manifest.json 字段

| 字段 | 类型 | 必填 | 约束 |
| --- | --- | --- | --- |
| `id` | string | 是 | 1~64 位，`^[a-z0-9][a-z0-9_-]{0,63}$`；不得为内置 `default` |
| `name` | string | 是 | 1~80 字符 |
| `author` | string | 否 | ≤80 字符（可为空串） |
| `version` | string | 是 | 1~20 字符 |
| `preview` | string | 是 | 包内 PNG 相对路径 |
| `roleAssets` | object | 是 | 非空；键 `^[a-z0-9_-]{1,32}$`，值为包内 PNG 相对路径（如 `{ "idle": "assets/idle.png" }`） |

示例：

```json
{
  "id": "my-skin",
  "name": "我的皮肤",
  "author": "开发者",
  "version": "1.0.0",
  "preview": "preview.png",
  "roleAssets": {
    "idle": "assets/idle.png"
  }
}
```

## 3. 安全边界（导入校验，违反即拒绝且不崩溃）

- 包内**只允许 `.png` 与 `.json`**；任何其他扩展名（`.exe`/`.bat`/`.cmd`/`.ps1`/`.sh`/`.dll`/`.js`/`.html`/`.svg` 等）一律拒绝；
- 包总大小 ≤ **10 MB**，文件条目数 ≤ **50**（zip 炸弹防护）；
- 路径必须为包内相对路径：拒绝绝对路径、盘符、`..` 跳转、控制字符、符号链接；
- 清单引用的 `preview`/`roleAssets` 资源必须真实存在于包内；
- zip 仅支持 store/deflate：拒绝加密 zip 与未知压缩方式，逐条 CRC32 校验；
- 导入先完整校验、后落盘；同 id 旧导入包仅在校验通过后覆盖；
- 主进程只做文件读写，**不执行包内任何代码**（无 child_process/eval 等机制）。

## 4. 内置默认皮肤

`src/main/default-skins/` 内置 3 套（清单 + 预览图 + idle 角色资源，均为程序生成的 PNG 占位图）：

| id | 名称 |
| --- | --- |
| `default` | 经典蓝 Classic Blue |
| `star` | 星夜紫 Starlight |
| `bunny` | 云朵粉 Cloud Bunny |

内置皮肤不可导入覆盖、不可移除；`default` 是 settings.skinId 的默认值。

## 5. IPC 契约

| 通道 | 参数 | 返回 |
| --- | --- | --- |
| `skin:list` | 无 | `{ ok, skins[], appliedId }`；每项含 `id/name/author/version/builtin/previewDataUrl/roleAssets{idle: dataUrl}` |
| `skin:import` | `{ path? }` | 缺省弹文件/目录选择框；成功 `{ ok, skin }`，失败 `{ ok:false, error }` |
| `skin:export` | `{ id, targetPath? }` | 缺省弹保存框；成功 `{ ok, path }` |
| `skin:apply` | `{ id }` | 校验存在后写入 `settings.skinId`；成功 `{ ok, settings }` |
| `skin:remove` | `{ id }` | 仅导入皮肤可移除；若移除的是当前皮肤，回退 `default` |

渲染层通过 `preload.js` 暴露 `petAPI.skin.{list,import,export,apply,remove}`；皮肤列表直接携带预览图与角色资源 data URL（符合 index.html CSP `img-src 'self' data:`）。

## 6. 导入→导出→重导入往返

导出 zip 的文件位于包根目录（无外层文件夹），因此导出的 zip 可直接重导入，清单与资源逐字节一致；`scripts/check.js` 以 `roundtrip` 皮肤做了完整往返断言。
