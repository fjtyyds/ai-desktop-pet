## 五、项目铁律与操作要点

- 事实只存在于文件：需求/决策/进度写入 SPEC、DECISIONS、STATUS、PLAN、任务卡；先写 ADR 再实施。
- 一个会话只做一个任务；任务边界以任务卡为准；只改“涉及文件”。
- 文档与代码同时提交；每个改动后 `npm run check` 必须通过；涉及 UI 用 `npm run dev` 人工目检。
- 环境：PowerShell 用 `npm.cmd`（不要用 npm.ps1）；`npm run smoke` 需真实用户权限；git 写操作需提权；沙箱内 Electron smoke 会因 GPU/AppData 失败属已知现象。
- 契约冻结：`src/shared/contracts.js`、`docs/API.md` 由协调者维护，任务线程只读；变更需先 ADR。
- 并行开发：每任务独立 worktree/分支；线程不自行合并 main；由协调者验收合并并解决共享文件冲突。
- 若应用“启动即退出”：先查托盘/进程/`%APPDATA%\ai-desktop-pet\lockfile`，旧实例占用单实例锁时 `taskkill /IM electron.exe /F` 后重启。
- API Key 已加密落盘（T-13）；不要把密钥写入文档/提交。
