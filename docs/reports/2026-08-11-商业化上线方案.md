# AI桌宠 v1.0 商业化上线方案（2026-08-11）

> 决策性质：本方案用于 M4 之后的市场化上线，含市场调研数据、竞品分析、优势功能、UI 方向、盈利模式与任务分配。所有市场结论均附数据来源；假设（转化率、ARPU）单独标注，需上线后遥测验证。

## 0. 结论摘要

1. **赛道成立且高速增长**：AI 情感陪伴全球市场 2025 年约 371 亿美元（同比 +31.6%，2030 预测 1408 亿美元）；中国 AI 情感陪伴 2024 年 12.11 亿元 → 2025 年预测 38.66 亿元 → 2028 年预测 595 亿元；AI 桌宠细分赛道年复合增长率约 75%。
2. **桌面宠物正处复兴窗口**：2025 年 Steam/桌面端出现“桌面宠物复兴”（cozy 游戏趋势）；Wallpaper Engine 以约 4 美元定价累计约 3200 万份、约 1.6~2.1 亿美元流水，证明“Windows 桌面个性化工具”可以规模化变现。
3. **纯 AI 聊天陪伴的留存与付费模型已跑通但很卷**：Character.AI 20M MAU / 年收入约 3000~5000 万美元；Talkie 2025 ARR 5310 万美元（+143.4%）；AI 陪伴 App 2025 年全球收入约 1.2 亿美元，单下载收入从 0.52 美元涨到 1.18 美元。但我们作为**桌面端 AI 陪伴+效率助手**，不与手机聊天 App 正面竞争，而是占据“陪伴 × 桌面效率 × 个性化”交叉空位。
4. **差异化结论（需要落地的优势）**：本地优先隐私 + AI 记忆人格 + 桌面原生效率（番茄钟/休息/天气/贴边）+ 开源可审计 + 皮肤生态 + 低价订阅/买断。六项缺一不可，否则会滑向“又一个聊天壳”。
5. **盈利途径（多样化，按优先级）**：①Pro 订阅（云 AI 额度+高级功能）；②永久买断；③皮肤/配件市场分成；④企业批量授权；⑤渠道销售（Steam/MS Store）；⑥赞助与联盟（GitHub Sponsors/爱发电/云厂商返佣）。
6. **上线节奏**：30 天冲刺（商业化基础→优势功能→UI 大改→发布），v1.0 目标 2026-09-01 全渠道上线（GitHub/官网/Steam/Microsoft Store）。

## 2. 竞品核心竞争力分析

| 竞品 | 核心能力 | 弱点（我们的机会） |
| --- | --- | --- |
| Character.AI / Talkie | 海量角色、UGC 剧本、强聊天体验 | 手机 App 为主，不占桌面；隐私争议；不解决“工作陪伴”；记忆与人格可复制 |
| Wallpaper Engine | 生态：创意工坊+3 美元低价+高好评 | 无 AI 对话、无记忆、无效率功能；纯壁纸 |
| Shimeji / Pixel Shimeji | 轻量、可爱、免费 | 无 AI、无对话、无效率、停止更新多 |
| Live2DViewerEX | Live2D 表现、Steam 低价 | 无 AI、无记忆、偏技术向 |
| Desktop Kanojo | 二次元桌宠形象 | 无 AI 对话、无效率、内容少 |
| PawPause / Sheepo / Cat Gatekeeper | 桌面宠物+休息/专注提醒 | 无 AI 对话、无记忆、无个性化角色、功能单一 |
| ropet（硬件） | 实体陪伴、高留存 | 2000 元门槛、无软件生态、无效率功能 |
| 火崽崽 / Pengu | 社交合养、病毒传播、高留存 | 手机端、无桌面场景、无 AI 深度对话 |

**结论**：当前市场上“AI 对话桌宠”与“效率陪伴桌宠”是两个半空位；同时具备【AI 记忆人格 + 桌面原生 + 效率提醒 + 皮肤生态 + 开源可信】的产品不存在。我们的机会是把这两个半空位合并成一个完整产品。

## 4. 目标用户与价值主张

### 4.1 目标人群（按优先级）
1. 18~35 岁独居/职场年轻人（AI 桌宠细分 CAGR 75%，创客中国数据；与 ropet 目标 25~40 岁女性重合）
2. 程序员/效率工具用户（桌面常驻、可定制、开源友好）
3. 二次元/桌宠爱好者（Shimeji/Live2D 用户，10M+ 安装基数）
4. 需要情绪陪伴但养不了真宠物的人群（ropet 用户画像）

### 4.2 一句话价值主张
> “桌面上会说话、记得你、还帮你专注的 AI 伙伴”——陪伴情绪 + 提升效率 + 保护隐私，三合一。

### 4.3 用户故事
- 小 A（大学生）：写论文时桌宠提醒喝水/休息，聊天发泄情绪，记忆里记住她的考试日期并主动提醒。
- 小 B（程序员）：自备 DeepSeek Key 免费使用；买永久版解锁全部语音音色与皮肤；把桌宠当第二大脑记录技术笔记。
- 小 C（二次元）：在皮肤市场下载/自制角色皮肤，分享聊天截图到小红书/B 站，形成传播。
- 企业 HR：给团队批量购买企业版，用统一人格的“入职助手”回答制度问题（远期）。

## 5. 优势功能清单（v1.0 必做）

1. **会说话的桌面伙伴**（已有）：点击角色即聊、流式输出、神经语音（含离线回退）。
2. **真的记得你**（已有+增强）：长期记忆、人格一致性、主动提醒（T-44 增强：把记忆与番茄钟/天气/日程联动）。
3. **效率陪伴**（已有+增强）：番茄钟、休息/喝水提醒、天气、专注统计、待办（T-44）。
4. **隐私可控**（已有）：本地加密记忆、BYOK、可完全离线；隐私面板公开透明（T-45 官网同步）。
5. **可换装皮肤市场**（新，T-43）：皮肤/配件/背景包（JSON+PNG 格式，可导入导出），创作者分成。
6. **分享即传播**（新，T-45）：一键生成对话卡片/表情包/桌面截图分享图。
7. **开源可审计**（已有）：GitHub 公开、SECURITY.md、CI 全绿。

## 6. UI 设计方案（数据依据）

依据 2026 趋势数据（§1.4）：
- **主视觉**：深色玻璃拟态（AI 输出区深色玻璃面板 + 微透明浮层 + 强对比文字），浅色主题可切换；避免全屏重模糊（2026 主流是“克制版玻璃拟态”）。
- **角色**：情绪可视化升级为“微动画角色”（呼吸/眨眼/表情联动，CSS/Canvas 实现，不引入重型引擎），支持多套默认形象。
- **布局**：桌面角色 + 可缩放聊天面板（最小 280×360）+ 右侧小组件栏（天气/番茄钟/专注统计，可折叠）；贴边吸附保留。
- **视觉规范**：圆角 12~16px、主色 #4160de（已验证对比度）、字号 ≥13px、焦点环/ARIA 保留无障碍基线。
- **动效**：过渡 150~240ms、消息流式光标、情绪变化 300ms 渐变；提供“减弱动效”开关（无障碍）。
- **图标/品牌**：渐变+微 3D 风格（2026 图标趋势），正式品牌页落地（T-45）。

## 9. 增长与营销（数据驱动的打法）

2. **KOL 合作**：B 站/小红书“桌宠”“AI 陪伴”“效率工具”分区种草；报价以千粉/播放数据为准（T-45 收集投放数据）。
3. **社区**：GitHub Discussions + QQ/Discord；皮肤创作者激励计划（分成 70%）形成 UGC 飞轮（Wallpaper Engine 模型）。
4. **SEO/ASO**：官网关键词“AI 桌宠、桌面宠物、AI 伴侣、desktop pet”；MS Store 关键词优化。
5. **留存机制**：签到式陪伴（每日一句）、记忆周年纪念、专注成就徽章（参考 Pengu D1 80% 的高留存靠关系感）。
