# 宠物浮窗（Codex Pets 式）优化方案（2026-08-13）

> 对应 ADR-045；任务卡 T-56~T-61；本方案是总工派活与验收依据。

## 一、现状盘点（T-55 已合并 main，cb92ec0）

已交付：

- 独立宠物浮窗（240×320 透明置顶小窗），位置记忆、收起按钮；
- 4 态状态机 idle/working/ready/failed，气泡自动回落；
- 设置页开关 + “显示/隐藏宠物”按钮、托盘菜单、`/pet` 命令；
- Codex 宠物包导入（pet.json + spritesheet.webp，8×9 图集）与行映射（idle/working/ready/failed）；
- check/smoke 断言与浮窗端到端测试。

## 二、与 Codex Pets 的差距

| 能力 | Codex | 当前 AI 桌宠 |
| --- | --- | --- |
| 点击宠物唤起主窗口 | 有（轻量双向通道） | 无 |
| 任务/状态气泡队列 | 有（进度更新、完成、需介入） | 单条气泡，无队列 |
| 状态细分 | running/waiting/review/failed + 进度 | 4 态 |
| 情绪/互动动画 | 9 行图集全状态 | 仅用 4 行 |
| 自定义宠物来源 | 扫描 ~/.codex/pets 目录 | 手动导入 |
| 设置项 | Pets 专区 | 一个开关 + 一个按钮 |
| 多显示器 | 跟随工作区 | 仅记忆坐标，无校验 |

## 三、优化方向与任务拆解

### 批次 1（并行 3 张卡，交互/状态/情绪）

**T-56 浮窗交互增强**

- 单击/双击宠物唤起主聊天窗口（再点隐藏）；
- 浮窗右键菜单：显示主窗口、收起浮窗、切换气泡显示、退出应用；
- Esc 收起浮窗；
- 浮窗拖动到屏幕边缘自动吸附（简化版贴边，不侵入主窗口 T-31 逻辑），位置继续记忆。

涉及：pet-overlay.js、overlay.html/css/js、main.js（注入 showMainWindow）、preload.js（如新增通道）、locales、check.js、smoke.js、T-56 卡。

**T-57 状态机与气泡队列**

- 状态扩展：speaking（TTS 朗读中）、attention（提醒/空闲互动）；
- 气泡队列：最多 3 条，每条按设置时长（petOverlayBubbleSeconds，默认 6s）轮播；
- 气泡开关与提醒透出开关（petOverlayBubbleEnabled / petOverlayReminders）；
- 空闲互动触发时主进程同时推送给浮窗气泡（主窗口隐藏也可见）；
- TTS 朗读开始/结束上报 speaking 状态（chat.js 已有 TTS 调用点）。

涉及：pet-overlay.js、overlay.js/css、chat.js、ipc 事件接线（main.js）、locales、check.js、smoke.js、T-57 卡。

**T-58 情绪与动画联动**

- 浮窗轮询 mood.get，happy/excited 时切到 waving（行 3）/jumping（行 4）动画；
- 等待输入用 waiting（行 6），回复完成用 review（行 8），出错用 failed（行 5）；
- reduceMotion 设置同步到浮窗（关闭动画）；
- 静态皮肤按情绪显示表情气泡。

涉及：overlay.js/css、pet-overlay.js（状态注入可选）、chat.js（如需要）、locales、check.js、smoke.js、T-58 卡。

### 批次 2（并行 3 张卡，皮肤/系统/设置）

**T-59 皮肤体验**

- 一键扫描导入本地 Codex pets 目录（~/.codex/pets 或用户选择目录），批量导入为皮肤；
- 皮肤列表为图集皮肤展示 9 行状态预览（当前仅首行动画）；
- 导入错误信息可读化（中文提示具体原因）；
- 导出保持 Codex 兼容（pet.json + spritesheet.webp）。

涉及：skin-store.js（新增目录扫描导入，不改安全边界）、chat.js/css、ipc.js/preload.js（如新增通道）、locales、check.js、smoke.js、T-59 卡。

**T-60 系统与性能**

- 多显示器：petOverlayBounds 增加 displayId，启动/恢复时校验目标显示器存在，否则回退主显示器右下角；
- 状态推送改为事件 + 低频心跳（5s），减少高频 IPC 轮询；
- 浮窗隐藏/页面不可见时暂停动画与轮询；
- 初始位置避开任务栏（基于 workArea）。

涉及：pet-overlay.js、overlay.js/css、store.js（displayId 字段，协调者已预冻结）、check.js、smoke.js、T-60 卡。

**T-61 设置与引导**

- 设置页“宠物浮窗”区块完善：气泡开关、气泡时长（3~20s）、提醒透出开关；
- 首次开启浮窗时气泡引导“我已出现在桌面右下角”；
- 设置说明文案完善（含宠物包提示）。

涉及：index.html、chat.js/css、locales、check.js、smoke.js、T-61 卡。

## 四、契约与设置预冻结（协调者先行，ADR-045）

协调者在本方案落地时先改 store.js/contracts.js，worker 只读：

- `petOverlayBubbleSeconds`：默认 6，允许 3~20；
- `petOverlayBubbleEnabled`：默认 true；
- `petOverlayReminders`：默认 true；
- `petOverlayBounds`：允许可选 `displayId`（整数），校验显示器存在。
- 契约：`petAPI.petOverlay` 新增 `showMain()`、`pushBubble({state,text})`、`getConfig()`（可选，由具体卡冻结后补充）。

## 五、自动化闭环流程

1. 建卡并提交方案（本文件 + ADR-045 + T-56~T-61）。
2. 批次 1 三个 worktree/分支就绪（node_modules 复用 junction），总工用子代理派活（每卡一个独立提示词）。
3. worker：读 AGENTS.md/PLAN/STATUS/DECISIONS/SPEC/API/自己任务卡 → 独立 worktree 实现 → `npm run check` 必须通过 → `npm run smoke` 尽量通过 → 更新任务卡 → 回报分支/提交/改动清单/验证结果。
4. 总工验收：diff 边界、check/smoke 复跑、冲突解决 → fast-forward/merge 到 main → 更新 PLAN/STATUS/任务卡。
5. 批次 2 同样执行；全部完成后 `npm run dev` 人工目检点交给用户，运行 sync-latest.ps1。
6. 每轮更新交接文件 `outputs/交接-宠物浮窗优化.md`（模板：docs/reports/2026-08-11-总工交接提示词模板.md）。

## 六、风险与回滚

- 共享文件冲突：chat.js/index.html/locales/check.js 被多卡触碰 → 总工串行合并解决，worker 不 rebase/merge main。
- UI 观感问题：自动化只能覆盖逻辑与像素断言，最终目检由用户确认；失败项打回重做，最多 2 次。
- 全部任务卡完成前 main 不被污染；回滚 `git reset --hard <合并前 commit>`。
