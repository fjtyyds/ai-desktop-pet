# 产品规格（MVP 基线）

## 定位

桌面 AI 桌宠：常驻桌面的角色化助手，能对话、有状态，最终开源并上架 GitHub、Microsoft Store、Steam。

## 目标平台与优先级

- 首发：Windows 10/11
- 后续候选：macOS、Linux（架构预留，不做承诺）

## MVP 用户故事

1. 用户启动应用后看到一个桌面小角色，可拖动、可置顶。
2. 用户点击角色或托盘图标可打开聊天面板，与 DeepSeek v4 Flash 对话。
3. 用户可在设置中配置 API Key、模型、角色名、窗口行为。
4. 应用本地保存对话记录与设置，重启后仍可读取。

## 非目标（MVP 明确不做）

- 语音输入/输出
- 任务提醒/日程
- 角色皮肤市场
- 移动端
- 云端账号体系

> 新增范围必须先写入 `docs/DECISIONS.md`，再更新本文档。

## 验收标准（M1 完成后统一核对）

- 完整走通：启动 → 聊天 → 保存记录 → 退出 → 重启找回记录
- LLM 调用失败时有明确错误提示，不阻塞 UI

## M2 智能层（规划）

### 用户故事

1. 重启应用后，聊天窗口恢复历史，桌宠记得之前聊过的关键事实。
2. 用户可在设置中配置人格（性格、语气、背景），回复风格随之变化。
3. 桌宠有情绪状态，交互会改变情绪并体现在回复语气中。

### 范围

- 短期记忆：最近 N 条消息窗口（默认 20）。
- 长期记忆：LLM 抽取的关键事实，本地 memories.json 存储（无向量库）。
- 人格与情绪：可配置人格 + 内存态情绪 + system prompt 注入。
- 渲染层启动恢复历史（petAPI.history.get）。

### 非目标

- 向量语义检索、云同步、多设备。
- 情绪持久化（M2 不承诺跨重启保持情绪）。

### 验收标准

- 重启后历史气泡恢复，且对话中能引用之前的关键事实（mock 或真实 LLM）。
- 人格/情绪设置影响回复风格。
- `npm run check`、`npm run smoke` 通过；涉及 UI 用 `npm run dev` 目检。
