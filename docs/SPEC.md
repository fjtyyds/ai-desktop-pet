# 产品规格（MVP 基线）

## 定位

桌面 AI 桌宠：常驻桌面的角色化助手，能对话、有状态，最终开源并上架 GitHub、Microsoft Store、Steam。

## 目标平台与优先级

- 首发：Windows 10/11
- 后续候选：macOS、Linux（架构预留，不做承诺）

## MVP 用户故事

1. 用户启动应用后看到一个桌面小角色，可拖动、可置顶。
2. 用户点击角色或托盘图标可打开聊天面板，与 DeepSeek v4 Flash 对话。
3. 用户可在设置中配置 API Key、模型、角色名、窗口行为。
4. 应用本地保存对话记录与设置，重启后仍可读取。

## 非目标（MVP 明确不做）

- 角色皮肤市场
- 移动端
- 云端账号体系

> 新增范围必须先写入 `docs/DECISIONS.md`，再更新本文档。

> 更新（M3.5，ADR-020/023）：语音输入/输出、任务提醒/日程已从非目标转为“M3.5 内容增强”范围（含技术验证门禁）。

## 验收标准（M1 完成后统一核对）

- 完整走通：启动 → 聊天 → 保存记录 → 退出 → 重启找回记录
- LLM 调用失败时有明确错误提示，不阻塞 UI

## M2 智能层（规划）

### 用户故事

1. 重启应用后，聊天窗口恢复历史，桌宠记得之前聊过的关键事实。
2. 用户可在设置中配置人格（性格、语气、背景），回复风格随之变化。
3. 桌宠有情绪状态，交互会改变情绪并体现在回复语气中。

### 范围

- 短期记忆：最近 N 条消息窗口（默认 20）。
- 长期记忆：LLM 抽取的关键事实，本地 memories.json 存储（无向量库）。
- 人格与情绪：可配置人格 + 内存态情绪 + system prompt 注入。
- 渲染层启动恢复历史（petAPI.history.get）。

### 非目标

- 向量语义检索、云同步、多设备。
- 情绪持久化（M2 不承诺跨重启保持情绪）。

### 验收标准

- 重启后历史气泡恢复，且对话中能引用之前的关键事实（mock 或真实 LLM）。
- 人格/情绪设置影响回复风格。
- `npm run check`、`npm run smoke` 通过；涉及 UI 用 `npm run dev` 目检。

## M3 打磨（规划）

### 用户故事

1. 用户可获得正式 Windows 安装包，应用有正式图标（桌面/托盘/安装程序）。
2. 应用崩溃或异常时本地留有日志，便于排查。
3. 界面文案可切换中/英文（en 为基础质量），键盘与读屏可用。
4. API Key 以加密形式保存在本机。

### 范围

- electron-builder + NSIS 打包，asar，正式 icon（assets/），dist 输出忽略。
- 崩溃与未捕获异常本地日志（crashReporter + logs/app.log）。
- 文案抽取 zh-CN/en，语言跟随系统 + 设置页切换；ARIA/焦点/对比度走查。
- API Key 加密存储（safeStorage/DPAPI）与旧明文自动迁移。
- 性能走查：消息列表 500 条滚动无明显卡顿。

### 非目标

- 自动更新、符号上传、远程崩溃平台接入（可后续）。
- 完整多语言质量保证（en 为基础翻译）。
- 代码签名与商店渠道（M4）。

### 验收标准

- `npm run check`、`npm run smoke` 通过；`npm run dist` 产出安装包，安装后启动冒烟通过。
- 崩溃/未捕获异常写入本地日志。
- zh-CN/en 可切换；无障碍走查无阻断项。
- apiKey 落盘为密文，旧明文数据自动迁移。

## M3.5 内容增强（规划）

### 用户故事

1. 对话以流式打字机输出，回复过程有“正在思考”反馈。
2. 角色会主动互动，情绪变化可见（表情/配色）。
3. 用户可查看/删除/修正长期记忆，可导出对话与清除数据。
4. 首次启动有引导（语言/密钥/人格），支持预设人格模板一键切换。
5. 窗口支持贴边隐藏、位置记忆与全局快捷键。
6. 可选扩展：系统状态、天气小部件、番茄钟、语音输入输出、图片理解（技术验证门禁）。

### 范围

- 流式回复（SSE + 打字机 + 取消/超时）。
- 空闲主动互动（本地话术池、节流）。
- 情绪可视化（mood → 表情/配色）。
- 记忆管理页（list/delete/修正）与对话导出/清除。
- 首次引导 + 预设人格模板。
- 贴边隐藏、位置记忆、全局快捷键。
- 批次 5（验证门禁）：系统状态与番茄钟、天气小部件、语音与图片。

### 非目标（M3.5 仍不做）

- 角色皮肤市场、移动端、云端账号体系。
- 自动更新与远程崩溃平台（M4 评估）。

### 验收标准

- 每个批次完成后 `npm run check`、`npm run smoke` 通过；涉及 UI 用 `npm run dev` 目检。
- 流式回复在真实 API 下逐字输出；取消/超时不卡死。
- 记忆管理、导出/清除与契约一致；情绪可视化与 mood 状态一致。
- 引导与人格模板重启后生效。
- 批次 5 各项以技术验证结论为准（通过则实现，不通过则记录降级）。
