常见问题

没有 API Key 能用吗？

可以。免费版提供每日 10 次云 AI 额度；升级 Pro 后每月约 200 次。自带 API Key 则不消耗额度。

聊天记录会传到服务器吗？

默认全部保存在本地。只有你主动开启云 AI 额度时，消息才会发往对应模型服务；BYOK 模式下直接连接你配置的服务。

分享卡片会泄露我的 API Key 吗？

不会。生成卡片时会自动隐藏 API Key、令牌与本地路径等敏感信息，且卡片只包含你选择的对话内容。

皮肤市场什么时候开放？

皮肤包导入/导出已在预览版可用；市场与创作者分成计划将在正式发布后上线。

永久买断和 Pro 订阅有什么区别？

永久买断一次付费解锁本地核心功能；云 AI 额度、云同步等在线能力属于 Pro 订阅。

是开源的么？

是。代码仓库公开、CI 全绿、安全政策公开，任何人都可以审计和参与贡献。
