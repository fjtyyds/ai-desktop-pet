# AI 桌宠（AI Desktop Pet）

基于 Electron 的 Windows 优先桌面 AI 角色助手：可对话、可记忆，计划开源并上架 Microsoft Store 与 Steam。

## 开发环境

- Node.js ≥ 20（本机 v24）
- npm

## 快速开始

```powershell
npm install
npm run dev
```

## 校验

```powershell
npm run check
npm run smoke
```
